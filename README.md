## 📌 Project Overview
**LEARNHUB** is a low-fidelity mobile application wireframe designed for an online education platform. Created as part of **CodeAlpha UI/UX Design Task 1**, this project focuses on structuring intuitive user architecture, visual hierarchy, and seamless navigation before moving into high-fidelity visual styling.

---

## 📱 Key Features & User Flow
The prototype consists of **8 interconnected core screens** mapped through Figma interaction flows:

1. **Welcome / Onboarding:** Clean introductory screen with a clear entry Call-to-Action (CTA).
2. **Home Dashboard:** Displays personalized greeting, active learning paths, and quick-access course cards.
3. **Categories:** Categorized view for filtering course topics (e.g., Web Development, UI/UX Design).
4. **Course Details (Web Dev & UI/UX):** Deep-dive views showing course description, instructor information, syllabus breakdown, and "Start Course" CTA.
5. **Interactive Lessons:** Dedicated video player container and key learning takeaways for active lessons.
6. **My Courses / Progress Tracking:** Overview of active learning progress, percentage completion bars, and finished modules.
